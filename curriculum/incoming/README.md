# 수동 확인 복구 — 공식 원문 넣는 곳

"교육과정 변경 감지 - 수동 확인 필요"로 남은 별책은 관리자가 **공식 원문 파일**만 지정하면 끝까지 자동으로 처리됩니다
(`.github/workflows/curriculum-recover.yml`).

1. 국가교육과정정보센터 > 교육과정 자료실 등 **공식 자료실**에서 그 별책의 **확정 원문**(hwp·hwpx·pdf·xlsx, zip 도 됨)을 받습니다.
   행정예고본·신구대비표 같은 확정 전 문서는 쓰지 않습니다.
2. 이 폴더 아래 `<고시 id>/` 폴더(예: `nec-2026-1/`)에 파일을 올리고, 같은 폴더의 `source.txt` 에 받은 곳 주소(https)를 한 줄 적습니다.
   파일 이름에 `[별책 15]` 처럼 별책 번호가 있으면 그 별책만 봅니다.
3. 올리면(push) 작업이 돌아 파싱 → 앞 판과 비교 → 검증 → 새 판 기록(scheduled/active) → 수동 확인 해제 → 전체 테스트 → 커밋·배포 → 이슈 닫기까지 합니다.
   조건을 통과하지 못하면 아무것도 바꾸지 않고 이슈에 까닭을 남깁니다. 처리를 마친 원문은 이 폴더에서 지웁니다(출처·sha256 은 기록에 남습니다).

로컬에서는 `node scripts/curriculum-standards.js recover 파일 --notice <고시 id> --volume <별책> --url <받은 곳> [--apply]`.
이 폴더는 배포되지 않습니다(사이트에는 css·js·data 만 올라갑니다). 학생 정보는 절대 넣지 않습니다.
