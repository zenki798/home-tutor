# 📚 가정교사

초등학생부터 성인까지, **교과과정을 순서대로 배우고 · 묻고 · 예상문제를 푸는** 무료 학습 사이트입니다.
학교급과 학년을 고르면 과목마다 "선생님"이 개념(이론)을 설명하고, 예제를 한 단계씩 풀어 보이고,
예상문제를 내서 바로 채점·해설해 주고, 심화학습까지 이끌어 줍니다.

- 주소: https://zenki798.github.io/home-tutor/
- **AI·서버·광고·회원가입 없음.** 입력한 내용과 학습 기록은 그 기기 밖으로 나가지 않습니다.
- `index.html` 을 더블클릭해서 열어도 똑같이 동작합니다. 휴대폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 무엇을 배울 수 있나

| 학교급 | 과목 |
|---|---|
| 초등학교 1~6학년 | 국어 · 수학 · 통합교과(1~2) · 사회 · 과학 · 영어(3~6) |
| 중학교 1~3학년 | 국어 · 수학 · 영어 · 사회 · 역사 · 과학 |
| 고등학교 | 공통국어 · 문학 · 화법과 언어 · 독서와 작문 / 공통수학 · 대수 · 미적분Ⅰ·Ⅱ · 확률과 통계 · 기하 / 공통영어 · 영어Ⅰ·Ⅱ / 통합사회 · 세계시민과 지리 · 사회와 문화 · 경제 · 현대사회와 윤리 / 한국사 · 세계사 / 통합과학 · 물리학 · 화학 · 생명과학 · 지구과학 |
| 대학교(교양·기초) | 미적분학 · 선형대수학 · 확률과 통계학 · 글쓰기와 독해 · 영어 · 경제학원론 · 심리학개론 · 일반물리 · 일반화학 · 일반생물 |
| 성인 | 다시 배우는 기초 수학 · 생활 속 수학 · 맞춤법 · 실용 글쓰기 · 영어 기초 문법 · 생활 영어 · 생활 법률·경제 상식 · 한국사 · 생활 속 과학 |

초·중·고는 **2022 개정 교육과정**을 따릅니다. 2015 개정 과정으로 배우는 학년(2026년 고3 등)은 과목 안내에 어느 과목과 같은지 적어 두었습니다.

## 한 단원에서 하는 일

| 탭 | 내용 |
|---|---|
| **개념** | 개념 카드를 한 장씩. 어려우면 "더 쉽게 설명해 주세요" |
| **예제** | 대표 문제를 한 단계씩 풀어 보이기 |
| **문제** | 예상문제 — 문제은행 + **매번 새로 만들어지는 문제**(수학), 바로 채점·해설, 틀린 문제는 오답노트로 |
| **심화** | 한 걸음 더 나아간 읽을거리와 심화 문제 |
| **질문** | 선생님께 묻기 — 사이트 안 내용에서 찾아 답하고, 계산·방정식 같은 수학 질문은 풀이 과정까지 보여 줍니다 |

### 질문에는 어떻게 답하나 (AI 없이)

- `3/4 ÷ 2/5`, `2x+3=7`, `x^2-5x+6=0`, `12와 18의 최대공약수`, `3.5km는 몇 m` 같은 **수학 질문은 직접 풉니다.** 학년에 맞는 말로 단계를 보여 줍니다.
- "광합성이 뭐예요?", "현재완료는 언제 써요?" 같은 질문은 **이 사이트의 개념·용어·자주 묻는 질문에서 찾아** 해당 단원으로 안내합니다.
  내 학년 내용에 없으면 가까운 학교급에서 찾아 "이건 중학교에서 배우는 내용이에요"처럼 어디서 배우는지 함께 알려 줍니다.
- 모르는 질문에는 **지어내지 않고** 모른다고 말한 뒤, 살펴볼 만한 단원을 알려 줍니다.

## 공부를 돕는 기능

- **오답노트 · 오늘의 복습**: 틀린 문제는 오답노트에 모이고, **다음 날** 홈 화면의 "📅 오늘의 복습"으로 다시 나옵니다.
  맞히면 **3일 뒤**에 한 번 더 확인하고, 두 번 연속 맞히면 오답노트에서 빠집니다. 한 번에 10문제까지 내고, 남으면 이어서 풉니다.
- **틀린 곳 알리기**: 문제(채점한 뒤)·개념 카드·예제마다 "🚩 틀린 곳 알리기"가 있습니다. 무엇이 이상한지 고르고 짧게 적으면
  **그 기기에만** 모아 둡니다(어디로도 보내지 않음). 보호자는 설정 → **틀린 곳 알림**에서 목록을 보고 [글로 복사하기]로 만든 사람에게 전해 줄 수 있습니다.
  복사하는 글에는 별명 같은 학생 정보가 들어가지 않습니다.
- **보호자용 학습 요약**: 기록 → "👪 보호자용 학습 요약". 지금 학생의 **최근 7일·30일** 공부한 날·푼 문제·정답률, 날짜별 막대,
  과목별 정답률, 잘한 단원·더 연습하면 좋은 단원, 자주 틀린 까닭, 오답노트·복습 현황을 한 화면에 모읍니다. [인쇄하기]와 [글로 복사하기](별명 없이)가 있습니다.
  계산은 그 기기 안에서만 하고, PIN을 건 학생은 PIN을 넣어야 볼 수 있습니다.
- **읽어 주기**: 개념 카드·예제·문제·해설 옆의 "🔊 읽어 주기"를 누르면 소리 내어 읽어 줍니다(분수·식은 "4분의 3", "7보다 크다"처럼 한국어로).
  **초등 1~3학년은 처음부터 켜져 있고**, 다른 학생은 설정 → 읽어 주기에서 켤 수 있습니다(빠르기: 천천히·보통).
  **그 기기 안의 목소리로만** 읽습니다 — 읽을 글을 인터넷으로 보내는 목소리는 쓰지 않으므로, 기기에 한국어 목소리가 없으면 버튼이 보이지 않고 설정에서 설치 방법을 알려 줍니다.
- **새 학년 안내**: 3월 1일이 지나 새 학년도가 되면 홈에서 "🌸 새 학년이 되었나요?"라고 묻습니다. [○학년으로 올리기]를 누르면 학년이 바뀌고,
  [그대로 두기]를 누르면 그 학년도에는 다시 묻지 않습니다. 학년이 맞아야 교육과정이 바뀔 때 알맞게 안내할 수 있습니다.

## 개인정보 · 학습 기록

- 학습 기록(진도, 푼 문제, 정답·오답과 틀린 까닭, 통계, 최근 질문 대화)과 별명은 **이 기기의 브라우저 저장소(IndexedDB)에만** 저장됩니다.
  서버가 없으므로 어디로도 보내지 않습니다. 페이지의 보안 정책(CSP)이 바깥으로 보내는 연결 자체를 막습니다.
- **한 기기를 여러 아이가 쓸 때**: 학생마다 기록이 완전히 나뉩니다. 학생마다 **PIN(숫자 4~8자리)** 을 걸면 그 학생의 화면·기록·오답노트·대화는 PIN을 넣어야 열립니다.
- 실명·생년월일·학교·연락처는 묻지 않습니다. 별명도 선택입니다.
- 설정 화면에서 그 학생의 기록이나 이 기기의 모든 기록을 지울 수 있습니다. 공용 컴퓨터에서는 공부를 마치면 지워 주세요.

### 다른 기기로 옮기기 (서버 없이)

설정 → **학습 기록 옮기기**

1. **내보내기**: 지금 학생 또는 모든 학생의 기록을 **암호로 잠근 파일**로 내려받습니다(암호 6자 이상).
   파일이 다른 사람 손에 들어가도 암호 없이는 열 수 없습니다. **암호를 잊으면 누구도 열 수 없으니** 잘 기억해 두세요.
2. **가져오기**: 다른 기기에서 그 파일을 고르고 암호를 넣으면, 내용을 끝까지 검사한 뒤 요약을 보여 줍니다.
   - **이 기기에 더하기**(기본): 지금 기록은 그대로 두고 학생을 더합니다.
   - **모두 바꾸기**: 바꾸기 전 상태를 남겨 두므로 **되돌리기**를 누르면 원래대로 돌아옵니다.
   - 암호가 틀렸거나 손상된 파일은 아무것도 바꾸지 않습니다.
3. 백업 파일은 학습 기록이 담긴 개인 자료입니다. 메신저·게시판에 올리지 마세요.

- 외부 글꼴·분석 도구·광고를 쓰지 않습니다(테스트가 외부 요청 0건을 확인합니다).

## 학습 내용에 대해

- 설명과 문제는 교육과정 성취기준을 참고해 **새로 쓴 것**입니다. 교과서·참고서·기출문제를 옮기지 않았습니다.
- 국어의 문학 인용은 저작권이 끝난 작품과 고전 문학만 씁니다.
- 학교 교과서와 선생님 말씀을 대신하지 않습니다. **틀린 곳을 발견하면** 그 자리의 "🚩 틀린 곳 알리기"로 모아 두었다가,
  설정 → 틀린 곳 알림에서 복사한 글을 [Issues](https://github.com/zenki798/home-tutor/issues)로 알려 주세요.

## 교육과정이 바뀌면

- **사람 손 없이 자동으로**: 매주 국가교육위원회 법령자료에서 새 교육과정 고시를 찾아 고시문을 읽고(바뀐 교과·학년별 시행일·새 과목),
  테스트를 통과하면 사이트에 스스로 반영합니다. 가정교사가 그 과목·학년 학생에게 **"📢 교육과정 소식"**으로 무엇이 언제 바뀌는지 알려 주고,
  새 과목이 생기면 지금 미리 공부할 단원을 이어 줍니다. 교육부 보도자료의 개정 소식(시안·공청회)은 저장소에 이슈로 알립니다.
- **성취기준까지 자동으로(확실할 때만)**: 고친 별책의 확정 원문을 공식 경로(국가교육위원회·국가법령정보센터·교육부)에서 찾아
  hwp·hwpx·pdf·xlsx 를 규칙으로 읽고, 기준 성취기준 2,000개(교육부 고시 제2022-33호 원문에서 뽑은 `curriculum/standards/`)와 비교해
  추가·삭제·변경을 찾습니다. 코드·과목·영역·학년 매핑·문서 읽기·시행일(두 공식 경로)까지 모두 확실할 때만 새 판을 따로 기록하고
  (지금 시행 판은 덮어쓰지 않음 — 학생에게는 그 학년의 시행 학년도부터, 보관·해시·되돌리기), 하나라도 확실하지 않으면 기존 자료를 그대로 둔 채
  **"교육과정 변경 감지 - 수동 확인 필요"**로 표시합니다. 그때는 관리자가 공식 원문 파일만 `curriculum/incoming/` 에 올리면 복구 작업이 끝까지 처리합니다.
- 설정의 **"교육과정 변경과 우리 학생"**은 이 기기의 학생마다 지금 학년과 앞으로 다닐 학년에 실제로 닿는 변경만 골라 보여 줍니다(기기 안에서만 계산).
- 교과별 성취기준이 크게 바뀌어 **설명·문제를 다시 써야 할 때**는 사람이나 작성 워크플로가 합니다.
  새 교육과정 지도를 넣으면 바뀐 단원에 **"개정 반영 중"**, 새 단원에 **"준비 중"**이 자동으로 붙고, 다시 쓰면 저절로 사라집니다.
- 차례: [docs/CURRICULUM-REVISION.md](docs/CURRICULUM-REVISION.md). AI·비밀 키·유료 서비스를 쓰지 않습니다.

## 직접 돌려 보기

```bash
# 그냥 index.html 을 열어도 됩니다 (서버 불필요)

npm install
npx playwright install chromium
node scripts/validate-content.js   # 학습 내용 검사 (정답·형식·문제 생성기)
npx playwright test                # 전체 테스트
```

Node 18 이상이면 됩니다. 외부 라이브러리를 쓰지 않습니다(테스트 도구 Playwright 만).
